Los cinco estados y uno más

  • pendiente también existe: el pago llegó pero el monto o la cuenta no coinciden con la operación (registro.py:147, :273).
  • incierto es el que hay que mirar: pey no contestó a tiempo y el cobro pudo haberse creado. No se reintenta para no cobrar doble (pey.py:168-183).
  • Solo el operador cierra un incierto, con python -m codi_informal.registro resolver <op_id> fallida|creada (registro.py:347).

De dónde sale cada transición

  • creando se escribe en crear_operacion, antes de llamar a pey (registro.py:89-98).
  • creada, incierto y fallida las marca el agente según lo que responda pey (agente.py:160-166, :205-211).
  • pagado lo marca _recibir cuando el pago concilia (registro.py:259).
